# Student-Performance-Analyzer
A program that collect student's subjects and its corresponding scores and calculate the average and determine the status(pass or fail) and give remarks based on the average

# Functions used
get_student_name()
get_score()
calculate_average()
determine_grade()
determine_status()
performance_remark()


# Function usage
get_student_name() - Get student's name
get_score() - Get subjects name and scores
calculate_average() - Compute the average scores of subjects
determine_grade() - Assign grade based on the average score
performance_remark() - Give remarks based on the average score

# How to run the program
User enters the name
Enter no. of subjects
Enter subject name and score
Program output average score, grade, status and remark of student
